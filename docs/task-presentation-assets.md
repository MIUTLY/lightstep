# 每项任务的表现计步、公共素材与本地手帐协议

2026-11-08。以本规则覆盖旧文件名、随机票根、按已完成叶子数换猫、轻承诺和旧计时描述。本轮只实施后端及公共素材托管；前端由原分工成员接入。

## 表现计步与真实进度

备忘录每项持久保存presentation_completed_steps，初始0；当前执行第几步=该值+1。每次成功complete只+1，轻中重相同；resize、闲聊、捕获新增、打开、走神、恢复、退出不增加。森林completed_leaf_ids仍是实际进度，不从表现步数推断叶子完成。

完成操作和计步在同一SQLite事务保存，request_id幂等及step_id过时校验仍有效。A/B/C计数独立；中途退出不清零，选其他项不会串号，重开及跨天继续读取原项。中途退出事件取当前执行号；整项完成事件取最后完成号，不+1。

items[].presentation、focus.presentation以及receipt事件presentation含：

```json
{
  "available":true,
  "completed_steps":1,
  "step_number":2,
  "normal_stage":"initial",
  "normal_pet":{"url":"/api/assets/v1/pets/initial-内容哈希.png","width":512,"height":476},
  "receipt":{"id":"1.2","url":"/api/assets/v1/receipts/1.2-内容哈希.jpg","preview":{"url":"预览图地址"},"composition":{}},
  "source":"recorded",
  "asset_version":"2026-11-08-v1"
```

示例省略bytes/sha256/source等素材元信息。URL为实际服务origin下的绝对路径，客户端用API服务origin拼接，不与含/api的基地址重复拼接。不得自行按叶子数、步数字段或走神形象重算票根。

## 素材目录与托管

GET /api/assets/manifest返回version、pets、receipts、journal、idle_policy等配置，不返回图片二进制。GET /api/assets/v1/...按需读取一张运行图，内容哈希文件名、长期不可变缓存，独立于LIGHTSTEP_SERVE_DEBUG_UI开关。原状态ZIP存于backend/assets/originals，不挂公共路由；31.4MB原票根ZIP的大文件上传被中断，本轮以工作区原包备份交付，不放Git（见originals/README.md），不影响已完整入仓的运行图。manifest记录两包归档及原文件SHA256。

6张桌宠为透明PNG运行图（最长边512），票根12张为JPEG运行图（1280×1908）及384×572预览图。原始两包ZIP在交付工作区逐字节保留，总约34.3MB，原票根需另行备份；运行图已全部入仓，总约6.3MB；客户端不要一次加载全部大图。新任务先取当前正常猫及必要的走神图，查看/保存回执时才取对应票根；预览、导出需要的加载由前端选择。下载失败使用本地占位/重试，不能禁用完成、调档或退出。

运行图通过backend/scripts/prepare_assets.py按比例缩放和编码，不重画素材内容、不填背景；使用Pillow离线构建，后端运行只读文件，无Pillow运行依赖。更新内容请升级版本或使用新哈希文件，不覆盖长期缓存文件。

## 五分钟前台未操作（前端实现）

idle_policy固定foreground_only=true、timeout_seconds=300、effect=pet_image_only；空闲只覆盖当前显示图片为pets.distracted（走神.png），正常形象仍以focus.presentation.normal_pet为准，不改服务器状态。触摸、输入、点击等重新等待，恢复正常猫；退后台取消计时，回来重新等待完整300秒。

单击不打开；双击打开原新增任务弹窗。打开/关闭/输入/提交既算用户操作，但不重建专注、不重置表现步数、不完成叶子。无“继续/结束”询问，不自动推进/退出；若第2步走神后退出，用退出事件冻结的1.2，不用走神图选票根。

用户本轮明确不恢复5/10分钟预约，现有410保持；预约与未操作换图是不同功能，未来恢复须独立实现。轻承诺起算/到期选择仍取消。

## 回执、日期与合成

receipt事件新增occurred_date（Asia/Shanghai实际结束日），原date仍是任务清单归属日。跨天退出不把昨天归属日印成今天的日期；前端按occurred_date归档本次保存。

票根本身印着固定2026.11.08，不能直接原样当成最终图片。每张receipt.composition提供原始1696×2528坐标系下：text_box、date_cover、date_patch_source、date_text_box。固定日期位置已逐张核对（4.2尤其偏上），前端先用同一底图的空白纸面区域覆盖旧日期，再绘制实际日期；不要在旧日期旁又写一份。坐标按最终画布等比缩放。

预览和导出用同一套Canvas合成：票根背景+用户文字+实际日期。先排版测量、换行；超过文字区时缩字号或提示缩短，不截断、不以省略号伪装完整保存。保存完成后的图片应包含用户文字。用户文字、合成图和私人留言不发送后端。文字长度/字号的最终交互与不同图片区域的视觉效果须微信实测。

## 手帐大底图与同日多页（前端实现）

manifest.journal目前available=false/background=null/reason=awaiting_supplied_background；底图未提供，不绘制替代图，不假报生成完成。回执保存可独立存在，手帐合成待素材齐备。

素材齐备后，一张大底图+一张已合成回执成为一页。用户主动保存生成本地page_id；同一次保存失败重试复用此ID，完整写入持久图片与日期索引后才提示成功。新的主动保存分配新page_id并追加，不以date或daily_journal事件ID作为唯一页键覆盖旧页。

本地索引建议date→pages[{page_id,receipt_event_id,image_path,created_at}]。日历标记有页日期，点击后逐页查看；同日多页和重开读取由前端管理。事件确认用于停止重投，和主动保存页的追加/防重分开处理。刷新或重复响应不自动新增页，用户再次主动保存可产生新页。删除任务或确认事件不能删除本地既有页。

旧/api/journal*继续410，不上传文字/合成图片，不恢复服务器手帐。素材公共托管与用户私有本地文件是两种数据。
