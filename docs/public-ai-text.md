# AI对外展示文案过滤

2026-11-07。用户要求后端不要将“（本次对话：…）”等内部说明原样交给界面展示。

后端JSON返回前统一处理展示字段：reply、current_step、question、summary、feedback、title、scope，以及completed_actions/remaining_actions/session_completed_actions中的文字。适用于闲聊、提问、专注步骤、回执事实、重开与旧操作响应重放；结构、字段名和接口参数不变。

- 删除带明确内部标签的完整中英文括号段，例如“本次对话：”“内部备注：”“系统提示：”“思考过程：”“回复策略：”，支持嵌套括号；删除完整的think/thinking标签块。
- “你好（本次对话：用户打招呼）”返回“你好”。
- 后端父任务原有“洗衣服（本次内容：放入衣物；加洗衣液）”返回“洗衣服\n放入衣物；加洗衣液”，动作明细保留。部分完成仍显示“这一段还剩：…”。前端不要根据完整父标题重建任务文案。
- 保留有用括号，例如“数学题（第1至10题，不含附加题）”“作文（不少于300字）”；不按“所有括号都不该显示”处理。
- 提示词要求AI只生成用户可见自然话语；真实AI闲聊过滤后没有正文时明确报AI返回不合格，允许重试，不用模板假装AI成功。

过滤是展示投影，不修改数据库任务森林、原始输入、完成集合、ID、会话、幂等键或范围覆盖。command/context/answers/original_input/plan/nodes等原始数据保留，不作为界面回复渲染；便签与私人留言不在本轮删改。重新打开和缓存的操作返回也经相同出口过滤，无需重新请求AI。

这是已知内部标签过滤，不承诺识别任意自然语言中的内部信息。无标签的普通括号和未闭合片段不擅自推断删除，避免丢失用户实际任务条件；出现其他真实样例可补充规则。前端继续使用返回的展示字段，step_id等身份字段不得从展示文字推算。

本轮只改后端和协议文档。微信换行/排版、真实供应商输出样本仍需联调，不能以隔离测试替代。
