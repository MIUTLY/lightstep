## 前端成员接入

- 将实际前端工程放在本目录，以已有源码结构为准，避免重复套一层工程目录。
- 提交源码时补充依赖安装、运行、打包命令和版本要求。
- 不提交 node_modules、dist、unpackage、真实密钥或 project.private.config.json。
- 后端接口位于 /api/*，本地默认 http://127.0.0.1:8000，接口文档位于 /docs。真机联调须使用设备可访问的服务地址。
- 模型供应商密钥由后端保存，不放在小程序源码中。

原有网页调试页保留在 backend/static/，启动方式见 backend/README.md。

## 已确认前后端分工

前端仅渲染服务端返回的任务状态，不在本地重复更新步骤进度或摩擦地图。打开或回前台时读取状态接口，发送完成/调整/退出动作后以响应为准。

前端A负责聊天、开始与单步交互；前端B负责生命周期、计时、动效、勿扰、感官模式、本地图片回执与手帐。详见 ../docs/architecture.md 和 ../docs/api.md。

回执图片和私人留言不上传：由用户主动保存，图片放持久本地文件，索引记录日期和文件路径；失败时提示未保存。旧 /api/journal* 接口已停用，不能继续调用。

backend/static/ 的浏览器文本手帐是可运行的本地保存示例，不能当作小程序图片手帐已实现。
